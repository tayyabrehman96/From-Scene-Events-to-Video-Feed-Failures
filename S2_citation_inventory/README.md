# S2 — Bibliographic citation inventory

`citation_inventory.csv` is the machine-readable inventory of the **177 references in the updated article**, including the LitStudy software citation used for the exploratory S3 evidence map. `role_in_review` is a heuristic from the title/entry type so a reviewer can filter datasets, review software, positioning reviews, reporting standards, and primary studies. It is not a substitute for S3 coding.
